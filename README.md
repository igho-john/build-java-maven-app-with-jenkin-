# DevOps Bootcamp — Jenkins CI/CD Projects

A collection of Jenkins pipeline projects built while learning CI/CD,
from basic syntax through a complete, production-style pipeline.

## Projects in this repo

| Folder | What it demonstrates |
|---|---|
| [`Jenkinsfile-version-increment/`](./Jenkinsfile-version-increment) |  Complete CI/CD pipeline — dynamic versioning, Docker build/push, automated deploy to AWS EC2 via Docker Compose, with loop-prevention |
| [`Jenkinsfile-simple-pipeline/`](./Jenkinsfile-simple-pipeline) | Basic Jenkins pipeline using a Shared Library |
| [`Jenkinsfile-kubernetes/`](./Jenkinsfile-kubernetes) | Early Kubernetes deployment exploration |
| [`Jenkinsfile-syntax/`](./Jenkinsfile-syntax) | Jenkinsfile syntax practice and experiments |
